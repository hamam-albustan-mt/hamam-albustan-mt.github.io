# سجل المتابعة البيئية لشركة حمام البستان

سجل المتابعة البيئية والتشغيلية لمزرعة حمام البستان: السبلة، العبوات والأدوية الخطرة، النافق والعنابر، نظافة المزرعة، الإجراءات البيئية، ملاحظات التفتيش، العقود والتراخيص، والتقارير الجاهزة للمركز الوطني للرقابة على الالتزام البيئي.

- **الاستضافة:** GitHub Pages (مجانية)
- **البيانات وتسجيل الدخول:** Firebase على الخطة المجانية Spark (بدون بطاقة)
- **الصور والعقود:** تنحفظ مصغّرة داخل قاعدة البيانات، فما تحتاج Firebase Storage المدفوع

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | الموقع كامل |
| `logo.png` | شعار حمام البستان |
| `firebase-config.js` | إعدادات مشروع Firebase (تعبّيها أنت مرة وحدة) |
| `firestore.rules` | قواعد الحماية: مين يقدر يدخل (تنسخها في Firebase) |

---

## الخطوة ١: مشروع Firebase (١٠ دقائق تقريباً)

1. افتح https://console.firebase.google.com وسجّل دخول بحساب Google.
2. اضغط **Create a project**، سمّه `hamam-albustan`، وتقدر تقفل Google Analytics، ثم **Create project**.
3. من الصفحة الرئيسية للمشروع اضغط أيقونة الويب **`</>`** (Add app → Web):
   - اكتب اسم: `hamam-albustan-web`
   - **لا** تعلّم على Firebase Hosting
   - اضغط **Register app**
   - بيطلع لك كود فيه `const firebaseConfig = { ... }`. انسخ القيم اللي داخله (apiKey, authDomain, projectId, …) وحطها في ملف `firebase-config.js` مكان `YOUR_...`.
4. **قاعدة البيانات:** من القائمة اليسار **Build → Firestore Database → Create database**:
   - اختر المنطقة **me-central2 (Dammam)** أو الأقرب لك (ما تتغير بعدين)
   - اختر **Start in production mode** ثم **Create**
   - افتح تبويب **Rules**، امسح اللي فيه، والصق محتوى ملف `firestore.rules`
   - غيّر `owner@example.com` لبريدك أنت (البريد اللي بتدخل فيه)، ثم اضغط **Publish**
5. **تسجيل الدخول:** **Build → Authentication → Get started**، وبعدها من تبويب **Sign-in method** فعّل:
   - **Google**: اختر بريد الدعم ثم **Save**
   - **Email/Password**: فعّل الخيار الأول ثم **Save** (هذا للعمال اللي ما عندهم Gmail)

## الخطوة ٢: GitHub والاستضافة (١٠ دقائق تقريباً)

1. افتح https://github.com/signup وأنشئ حساب، أو سجّل دخول إذا عندك حساب.
2. اضغط **+** فوق ← **New repository**:
   - Repository name: `hamam-albustan`
   - اختر **Public** (الاستضافة المجانية تحتاجه عام، وبياناتك محمية في Firebase مو في الكود)
   - اضغط **Create repository**
3. في صفحة المستودع اضغط **uploading an existing file**، واسحب الملفات الأربعة (`index.html`، `logo.png`، `firebase-config.js` بعد ما عبّيته، `README.md`)، ثم **Commit changes**.
4. **Settings ← Pages**: في **Branch** اختر `main` و `/ (root)` ثم **Save**.
5. انتظر دقيقة أو دقيقتين، بيطلع لك الرابط:
   `https://اسم-حسابك.github.io/hamam-albustan/`

## الخطوة ٣: ربط الرابط بـ Firebase

في Firebase: **Authentication → Settings → Authorized domains → Add domain**، واكتب:
`اسم-حسابك.github.io`

بدون هذي الخطوة، الدخول بحساب Google ما يشتغل.

## الخطوة ٤: نقل سجلاتك القديمة

1. افتح الصفحة القديمة على claude.ai ← **الرئيسية** ← **النسخة الاحتياطية** ← **تنزيل نسخة احتياطية**. هذا ينزّل ملف `.json` فيه كل السجلات وصور العقود والسندات.
2. افتح الموقع الجديد وسجّل دخول ← **الرئيسية** ← **النسخة الاحتياطية** ← **استرجاع من نسخة**، واختر الملف.

## إضافة عامل أو مشرف

1. في Firebase: **Firestore Database → Rules**، أضف بريده في القائمة، مثلاً:
   ```
   'owner@gmail.com'
   , 'worker1@gmail.com'
   ```
   ثم **Publish**.
2. أرسل له الرابط. يدخل بحساب Google، أو يضغط **أنشئ حساب** ويسجّل بنفس البريد.
3. للعامل: أرسل له الرابط وفي آخره `#worker` عشان يفتح على وضع العامل مباشرة، مثلاً:
   `https://اسم-حسابك.github.io/hamam-albustan/#worker`

## تحديث الموقع لاحقاً

إذا عدّلنا `index.html`: افتح المستودع في GitHub ← اضغط على الملف ← أيقونة القلم، أو **Add file → Upload files** وارفع النسخة الجديدة فوق القديمة ← **Commit changes**. الموقع يتحدّث خلال دقيقة أو دقيقتين، وبياناتك ما تتأثر لأنها في Firebase.

## الفرق عن نسخة claude.ai

| الميزة | في هذي النسخة |
|---|---|
| التسجيل بالصوت | ميكروفون المتصفح (Chrome أو Edge أو Safari)، مجاني |
| توزيع الكلام على الأقسام | قواعد مكتوبة في الصفحة تفهم الكلام الخليجي المعتاد (سبلة، نافق، عبوات، دواء، نظافة، موعد…). دايماً تطلع بطاقة مراجعة قبل الحفظ، صحّح فيها إذا لزم |
| تقويم Google | بعد كل موعد يطلع لك زر **📅 أضف لتقويم Google**، تضغطه وتحفظ الموعد. التعديلات اللي بعدها ما تنتقل للتقويم تلقائياً |
| الصور والعقود | تتصغّر تلقائياً. ملف PDF حدّه تقريباً ٦٠٠ كيلوبايت، إذا أكبر صوّر صفحاته وارفعها صور |
| مين سجّل | من حساب الدخول (Google أو البريد) |

## حدود الخطة المجانية (Spark)

- ٥٠٬٠٠٠ قراءة و٢٠٬٠٠٠ كتابة في اليوم
- ١ جيجابايت تخزين لقاعدة البيانات

هذا يكفي مزرعة بعدة عمال بسهولة. ولو وصلت الحد يوم من الأيام، الموقع يوقف لين اليوم الثاني، وما ينخصم منك أي مبلغ لأنه ما فيه بطاقة مربوطة.
